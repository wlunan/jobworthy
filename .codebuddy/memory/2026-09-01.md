- 补充修复：换内联 SVG 后仍不显示。第二根因：ui.css（后引入，浅色主题）把 .top-bar 背景从 index.css 的紫色渐变覆盖为米白 rgba(252,251,248,.9)，但 .gh-link 的 color 仍是 index.css 的白色 rgba(255,255,255,.85)，白图标+白背景看不见。已在 ui.css 补 .gh-link{color:var(--ui-text)} + hover 主色适配。教训：改主题（ui.css 覆盖 index.css）时，依赖旧主题配色的组件（如白色图标/文字）需一并重定义。
- 再修复：颜色仍和背景接近。终方案：不依赖 currentColor 继承链（受主题覆盖/浏览器缓存影响大），改为内联 SVG 硬编码 fill="#24292f"（GitHub 官方黑）+ 内联 width/height=18，即使 CSS 被缓存也能显示深色；ui.css 仅做 hover 增强（.gh-link svg{fill:#24292f}、:hover 背景浅主色+fill 变 var(--ui-primary)）。教训：图标颜色别走 currentColor 继承，直接硬编码 fill 最稳。
